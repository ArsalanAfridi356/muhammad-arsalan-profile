# Muhammad Arsalan, Industrial Engineer, Portfolio V3

A custom Next.js portfolio focused on industrial engineering, maintenance and reliability, ERP workflows, operations, process improvement and data-driven systems.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy

Push the project to GitHub and import the repository into Vercel. Vercel will redeploy automatically after future GitHub commits.

## Content basis

The profile content is based on the supplied LinkedIn profile PDF. No private source documents are included in this repository.
